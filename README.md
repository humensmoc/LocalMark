# 本地摘录 · Web Clipper

面向桌面 Chrome 的本地网页批注插件。选中文字即可高亮、写评论；在侧栏给整个网页添加多个标签。JSON 保存完整标注和定位信息；设置中的「自动生成 Markdown 文档」默认关闭，开启后才为有高亮、批注或非空网页评论的网页生成阅读副本。无账号、无批注服务器、无需安装本地辅助程序。

## 安装现成版本

当前版本为 **0.3.6**。浮窗已移除快捷键说明、查看摘录和取消按钮，「删除」位于浮窗顶部；「保存」仅在输入框展开后显示，悬浮于框内右下角。划词后直接在鼠标旁显示两行浮窗：上排颜色、下排自动聚焦的批注输入框，点击或打字时展开，按住上排空白处可拖动；点击已有高亮使用同一浮窗。设置中的「划词标注浮窗」默认粉、黄、绿三色，可自选颜色并增减至1～8色。完整版本记录见 [Progression.md](Progression.md)。高亮统计与分组开关固定于筛选区下方；分类和标签占比图采用区分明显的蓝、橙、紫、青绿等配色，保留圆角与细边框，搜索和缩放保持颜色；详情中的关联网页使用统一网页卡片，网站图标加载时立即显示站点首字母及背景占位。元素和文字标记的悬停预览只显示白色评论正文，随鼠标连续移动，靠近屏幕边缘时自动避让；无评论或仅空白时显示「无评论」，文字高亮、定位轨道和元素标记保持一致。三处筛选区采用紧凑排布，名称与单选/多选说明同行，默认随内容自动收缩，较多标签最多占180px并在内部滚动；手动拖动可指定高度，双击下边缘恢复紧凑自动高度。高亮内容右上角新增可记忆的「按网页分组」开关：开启时每组以独立网页信息卡开头，每个网页另起一行且顶部对齐，底部保留随列高变化的轮廓和不同底色，内外拐角平滑圆角过渡；关闭时每条标注恢复来源、标签、日期与评分。侧栏最近网页和标签页共用仪表盘网页卡片；评分固定于主分类和标签右侧，标签较多时在左侧自动换行，不占用评分区域；多选入口与网页数量同行。独立批注标签页已移除，批注继续随高亮展示。侧栏标签页及仪表盘网页、高亮共三处筛选区均可折叠、拖动下边缘调整高度，并分别记住布局。网页卡片按最近修改顺序紧凑填入最短列，每列上下只保留10px间距，窗口或内容尺寸变化时自动重新排列。高亮和批注卡片最高 480px，较矮窗口自动缩小；超长内容在卡片内滚动，关闭分组时每条标注的底部来源、日期和评级固定，短卡片保持自然高度。支持 DOM 元素标注，可圈住图片、卡片或内容模块并写批注。网页右边缘中间默认常驻元素选择按钮，无需展开侧栏，再次点击或Esc退出；上方眼睛按钮切换本页高亮与标注显示，刷新后恢复显示。右侧另有侧边栏按钮，点击展开、再次点击关闭；设置中的高亮显隐、元素选择和侧边栏三个按钮开关可分别显示或隐藏，默认开启并记住选择。主分类与子标签支持按网页数量分配面积的「占比图」，网页卡片突出高亮、批注数量。侧栏和仪表盘支持拖入一个或多个文章 JSON；侧栏仅在文件拖入时显示提示，仪表盘仍可点击「导入 JSON」选择文件。当前页面的网址下方提供「打开元数据位置」「复制文件名」和「下载 JSON」。仪表盘左侧提供网页、主分类、子标签、高亮内容和颜色五个视图。更新后重新加载扩展并刷新网页，同时重新打开或刷新仪表盘；侧栏与网页脚本版本一致时底部显示「版本 0.3.6」，不一致时分别显示，仪表盘左侧底部和状态栏显示 v0.3.6。旧文字数据兼容 v1/v2，含元素标注的网页保存为 v3。 多选时点击整张网页卡片即可勾选或取消；点击「导出所选网页」并选择目标文件夹（可以非空），按首次收藏日期写入 data/YYYY-MM/DD/文章标题--网页ID.json，保留完整 JSON 元数据。导出不会更换当前资料库目录。

1. 在 Chrome 地址栏输入 `chrome://extensions`，打开右上角「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本项目的 **`dist` 文件夹**，不要选择项目根目录。
3. 在工具栏的扩展菜单中固定「本地摘录 · Web Clipper」。
4. 打开一个普通网页，点击插件图标，在左侧栏底部点击齿轮加文字的「设置」按钮；也可右键浏览器工具栏的插件图标选择「选项」，或在扩展详情页打开「扩展程序选项」。底部仅一行显示目录、保存状态、仪表盘和设置；目录或状态过长时悬停可查看完整文字。
5. 在设置页点击「选择文件夹」，选择一个专用摘录目录并允许读写。可以选择 Obsidian Vault 中的子文件夹。需要 .md 文档时，开启同一区域的「自动生成 Markdown 文档」；默认关闭，旧安装升级后也需手动开启。开启后会补生成已有内容，关闭后仍保存标注及 JSON，保留已有 .md 文档且不再更新。
6. 安装前已打开的网页建议刷新一次。更新插件时在扩展管理页点击刷新，并刷新网页。

原生侧栏基础功能已在 Chrome 128.0.6613.114 与 Chrome for Testing 153 中进行扩展集成测试。最低支持 Chrome 128：旧版通过关闭原生侧栏文档来收起侧栏，支持新关闭接口的浏览器使用该接口。无需运行 Node 或保持设置页打开，后台服务负责保存。

自定义色随高亮保存为六位十六进制色值；修改色板不会改变旧高亮。共享含自定义色的 JSON 时，接收方也需要使用 0.3.3 或更新版本。

## 操作

| 操作 | 效果 |
| --- | --- |
| 选中文字 | 鼠标旁立即出现颜色和输入框，输入框自动聚焦；直接打字或点击输入框会展开 |
| 点击浮窗颜色 | 用所选颜色保存高亮和当前批注；也可按 Enter 或点击展开后的输入框内保存按钮 |
| 拖动浮窗上排空白处 | 移动浮窗，输入时保持拖动后的位置 |
| 设置 → 划词标注浮窗 | 自选1～8种颜色，默认三色，保存后应用到已打开网页 |
| 点击网页右边缘中间常驻的元素选择图标 | 移动鼠标预览，↑ 选择父级、↓ 返回子级，左键点击直接打开当前元素的批注编辑框。提示条仅显示元素名称和操作提示；Esc 或再次点击图标退出，关闭侧栏后仍可使用 |
| 点击元素按钮上方的眼睛 | 隐藏或恢复本页已保存的高亮、元素框、批注预览及定位轨道；数据保留，刷新网页后恢复显示 |
| 设置 → 网页标注工具 → 显示网页悬浮按钮 | 默认开启；关闭后两个按钮消失，已有标注恢复正常显示，设置会被记住 |
| 悬停已标注元素，再点击右上角铅笔 | 悬停时展示评论并显示铅笔，离开后隐藏；点击铅笔编辑颜色、单条批注或删除标注。框内仍可划词，原网页链接和按钮保持可用 |
| 悬停左边缘彩色位置条 | 仅预览该条评论正文（如有），支持移入预览滚动阅读 |
| Enter / Shift+Enter / Esc | 保存 / 批注换行 / 取消；输入法选字不触发保存 |
| 悬停原文高亮 | 显示批注；点击进入编辑 |
| 点击重叠高亮 | 选择要编辑的标注 |
| 点击插件图标 | 打开或收起浏览器原生侧栏 |
| 点击网页右侧侧边栏按钮 | 展开或关闭原生侧栏；右侧三个按钮均可在设置中分别隐藏和开启，默认显示 |
| Ctrl+B（Mac：Cmd+B） | 浏览器处于前台时打开或关闭原生侧栏；输入框中也生效，此组合键将用于侧栏开关 |
| 点击侧栏摘录或左侧彩色轨迹 | 滚动定位并短暂强调原文 |
| 点击「链接」 | 文字标注复制原生文本定位链接；元素标注复制网页链接，恢复元素框需要对应 JSON 和支持 v3 的 LocalMark |
| 点击「未定位 · 重新绑定」 | 按原标注类型重新选择文字或元素后确认，保留原标注 ID、评论、标签和颜色 |
| 在「当前页面」或仪表盘网页详情点击 1–5 颗星 | 立即保存网页评分；点击「清除」恢复未评分，无需先高亮或写评论 |
| 点击「当前页面」网址下的「打开元数据位置」 | 在系统文件选择窗口中打开文章 JSON 所在的日期目录；「复制文件名」可辅助定位，旁边的「下载 JSON」可直接通过浏览器下载 |
| 将一个或多个文章 JSON 拖入侧栏或仪表盘，或点击仪表盘的「导入 JSON」 | 拖入时显示提示；导入到当前连接的目录，完成后逐文件显示结果 |

导出所选网页时，会递归扫描目标文件夹内的 JSON，按网页 ID 或规范化网址识别重复。内容相同的文件自动跳过；有差异会弹出新旧内容对比，每个冲突文件可独立选择，也可勾选批量设置或全部采用新文件／旧文件。全部冲突选择完成后点击「确认并导出」，取消则不写入。新网页使用日期目录，采用新版本会替换对应旧文件；同网址但不同网页 ID 时同步文件名后缀。确认前若目标相关文件发生变化，会要求重新检查，完成后显示新增、替换、跳过及保留数量。

导入前需要在设置中连接目录并允许读写。支持本插件导出的新旧版文章元数据 JSON，保留高亮、批注、评论、评分和收藏时间，按收藏日期保存到 `data/YYYY-MM/DD/文章标题--网页ID.json`；分类和标签按名称关联到当前资料库。已有相同文章 ID 或网址时跳过并保留当前版本，损坏文件单独报错，不影响同批其他有效文件。只有写入完成才显示「已导入」；写入失败的内容显示「待同步」，可在设置中处理后重试。Markdown 是否生成沿用当前设置，默认关闭。每批最多 500 个文件、总计 32 MB，单个文件最多 16 MB；不支持拖入文件夹或「分类标签.json」索引。

元素框绘制在插件独立覆盖层，不给原元素添加边框、包装节点或改动样式；滚动、布局变化和窗口缩放时更新位置，并按滚动容器裁剪。支持顶层普通 HTML 元素；上下方向键沿鼠标命中的节点链调整范围，不是任意矩形框选。空节点或无法区分的重复元素会提示扩大范围。原元素被删除、隐藏或内容被替换时保留批注并显示未定位，可重新绑定；文本、图片及链接等身份线索必须匹配，不按过期的第几个子节点猜测。未保存时按 Esc 或取消退出。

元数据位置入口使用已授权的本地文件句柄，目标是「data/YYYY-MM/DD/文章标题--网页ID.json」，包括只有评分或标签、没有 Markdown 的文章。日期取文章首次收藏时间 createdAt 的本机日期，月份和日均补零；后续修改不会按 updatedAt 重新归档。按钮下显示文件名，旁边可复制完整文件名或下载 JSON。下载使用浏览器已保存的当前文章数据，包括尚未同步到本地文件的改动，无需连接或授权目录；下载位置由浏览器设置决定。浏览器的文件选择接口只能指定初始目录，不能预选或高亮某个文件；选择或取消均不会导入或修改文件。尚未保存、目录未连接、权限失效或文件缺失时会显示原因，不自动创建空文件。

旧版「网页ID.json」在同步时自动改为可识别的标题文件名；在插件中修改标题后，JSON 名称也会更新。标题中的非法字符会替换，过长标题会截短，末尾的稳定网页 ID 用于区分同名文章。改名先复制并逐字节核验新文件，再清理未发生变化的旧文件；相同内容的中断副本可以继续清理，不同内容的重复文件会暂停同步并提示核对。JSON 内的文章 ID、URL、标注及已有 Markdown 名称不因改名而改变。

网页卡片用五个小圆点显示评分：对应星数为实心，其余为空心；未评分时全部为空心。1–5 星分别使用红、橙、金、绿、紫色，悬停可查看具体分数。侧栏最近网页、标签和仪表盘网页卡片统一使用右下角留白，不增加卡片高度；高亮分组网页信息卡及关联网页的来源行也显示评分。评分随 JSON 保存与恢复，已有内容的 Markdown 同时导出 `rating` 属性；仅评分仍不单独生成 Markdown。

侧栏顶部将「最近网页」「标签」「当前页面」与小号关闭按钮放在同一行，去掉单独的品牌标题区。每个已保存网页始终有一个主分类，另有零到多个小标签；主分类在顶部单选，支持搜索、新建与查看同类网页。预置未分类、游戏设计、交互设计、视觉设计、游戏营销、游戏分析、访谈；旧数据迁移为“未分类”，原标签全部保留为小标签，之后可自行选择实际主分类。小标签仍使用“+”搜索、新建和多选；空搜索列出全部已有小标签，按关联网页数量排序并显示计数。主分类与小标签各自独立，不根据主分类限制小标签。标签页上方为紧凑横向换行的筛选区，下方为独立滚动的网页卡片。主分类单选，小标签多选且同时满足，搜索与筛选条件叠加；再次点击可取消条件，也可清空筛选。标签数字表示当前其他条件下的匹配网页数，未选且数量为 0 的主分类和小标签自动隐藏，已选项即使为 0 也保留，方便取消。最近网页和标签页统一使用仪表盘网页卡片：站点图标与背景、两行标题、主分类与子标签、单行评论摘要、大号高亮/批注计数、右下角评分，卡片间距10px；零计数隐藏，去掉展开摘录和查看完整评论。点击卡片打开对应网页。卡片不显示网址、日期或“网页评论”标题，未筛选时显示全部网页。分类信息随逐页 JSON 保存，读回后重建已使用的分类与标签。侧栏占用浏览器分配的独立区域，网页在剩余视口中重新排版，关闭后恢复。左右位置由浏览器设置决定：在 Chrome 设置的「外观」中将侧栏位置设为左侧，即可让网页向右腾位。Ctrl+B 未生效时，在 `chrome://extensions/shortcuts` 检查「本地摘录」的「激活扩展程序」是否绑定为 Ctrl+B，并处理其他扩展的快捷键冲突。侧栏随当前窗口的活动标签页切换；在浏览器内部页只显示不可摘录提示，仍可浏览已保存的文章。未保存的标题和评论草稿在同一次浏览器会话中可跨侧栏关闭恢复；重启浏览器或重载扩展前请先保存。

## 本地数据

### 文章管理大窗口

点击侧栏底部、设置旁边的「仪表盘」按钮，或在设置页点击「打开文章管理」。默认打开 1440 × 920 的独立窗口，可以拖动、调整大小；再次点击会聚焦已有窗口。

“多选 / 退出多选”与网页数量同行；只有进入多选后才展开选择统计和批量操作区。默认打开「网页」视图，宽窗口分为三栏：左侧为视图导航，中间顶部是主分类、子标签筛选，下方为文章卡片，右侧为文章详情。搜索放在最上方，与刷新、设置并列，不再显示单独的视图标题栏。筛选支持主分类单选、子标签同时满足和清空筛选，标签较多时在筛选区内部滚动。侧栏标签页，以及仪表盘网页、高亮内容页的筛选区，均可点击标题旁的「收起 / 展开」折叠，折叠保留当前筛选并显示已选项数；拖动区域下边缘的横线可调整高度，双击恢复随内容收缩的紧凑自动高度，也支持上下方向键微调。三处高度与折叠状态分别保存，窗口变矮时限制筛选区高度，给结果留出空间。高亮和批注按所属网页的主分类、标签筛选，标签上的数字表示当前条件下的网页数，搜索仍逐条匹配摘录；网页与高亮视图各自保留筛选选择至窗口刷新前。网页卡片按最近修改顺序放入最短列，同高时从左到右排列，避免列内留下多余空白，结果区独立竖向滚动。卡片用大号数字展示高亮与非空批注数量，各项为 0 时隐藏；两项都为 0 时不显示计数区域，评论仅显示一行摘要，不再提供「展开摘录」「查看完整评论」。点击整张文章卡片（包括数量、标题、标签、评论或空白处）即可在右侧查看和编辑完整内容；需要访问来源时使用详情中的「打开原网页」。极窄窗口按导航、筛选、列表、详情上下排列。

- 「主分类」「子标签」可在列表顶部切换「卡片」「占比图」，分别记住选择。占比图按关联网页数量分配色块面积；搜索后按当前展示项目重新计算占比，零网页项目单独列出。子标签可跨主分类复用，同一网页可以计入多个标签，因此占比的分母是标签关联总数。悬停色块可查看完整名称、数量和占比，「数量明细」按数量排序，便于查看小色块。点击卡片或色块可在右侧直接修改名称与说明、查看关联网页、跳转网页筛选及合并、删除管理。新建对话框只显示创建表单。
- 「颜色」展示五种高亮颜色及各自的高亮数量，右侧可记录颜色的含义、使用习惯，并阅读该颜色的全部高亮及批注。
- 「高亮内容」右上角可切换「按网页分组」，默认开启并记住选择。开启时，每个网页先显示一张与网页页相同的独立信息卡，后面完整保留所有匹配摘录和批注；每个网页另起一行，首排卡片顶部对齐；组内按最短列紧凑排列，底部边框随实际卡片高度转折，交替底色区分网页。组间保留18px间距，卡片较少时按实际列数铺满整行。组内保持最近修改顺序；关闭时按修改时间混排，每条标注都显示所属网页标签、来源、日期和评分。开关不改变数据或筛选，搜索、缩放和刷新后重新排布，窄屏单列。点击网页信息卡或来源进入详情编辑。
- 搜索针对当前视图：分类、标签、颜色搜索名称和说明，高亮搜索逐条原文、批注与来源信息。切换视图会清空搜索，已有文章和说明草稿保留到当前仪表盘关闭或刷新前；离开时有未保存内容会提示。
- 分类、标签说明保存在「分类标签.json」各项目的可选 `description` 字段，颜色说明保存在可选 `colorDescriptions` 字段；旧文件缺少这些字段时显示为空。说明随全库同步、支持外部读回和并发冲突保护，单独修改说明不会重写网页 JSON 或 Markdown。备份和移动资料库时应包含此分类文件。

- 详情直接编辑主分类、增删标签；这些操作即时保存。描述沿用已有「网页评论」字段，点击「保存评论」保存。
- 已有高亮可以修改摘录展示文字、颜色、批注或删除。编辑展示文字保留原文定位锚点与标注 ID；需要改变定位时，在原网页使用「重新绑定」。新增高亮仍需在原网页选择文字。
- 评论和高亮草稿按文章保留，切换文章、筛选或刷新本地数据不会清空；刷新或关闭管理窗口前应先保存，浏览器会对未保存编辑提示离开确认。
- 管理窗口与侧栏共用浏览器缓存、逐页 JSON 和 Markdown。窗口获得焦点或点击「刷新本地数据」时读取外部改动，可见时也每 15 秒检查一次。并发修改会保留草稿并提示冲突，文件冲突在设置中处理。
- 点击右上角「分类与标签管理」，通过带数量的分类/标签切换、可搜索的整行选择项、独立编辑区及合并移除区管理资料库。弹窗、导航、筛选区及输入控件统一黑色背景，选中项与主要操作使用绿色。可新建、重命名、合并或删除主分类和标签。重命名保留 ID；同名重命名会明确询问是否合并。删除主分类时转入所选分类，默认转入「未分类」；「未分类」不可删除或重命名。删除标签只清理关联，文章、评论与高亮保留。空分类和空标签也会保留，默认分类只在首次初始化时提供。
- 勾选文章，或「全选当前筛选结果」，可更改主分类、批量添加或移除多个标签。添加会去重并保留原有标签，移除只影响所选文章，不删除全局标签；候选标签显示所选文章中的使用数量。改变搜索或筛选会清空选择。操作前会核对选中的关联是否已被其他窗口修改，有冲突时整个批次拒绝保存。
- 全库操作先读取本地数据并检查冲突，修改后立即保存浏览器缓存，再同步文件。界面显示实际修改数量；文件部分失败仍会显示待同步或冲突，不能仅凭浏览器保存提示视为磁盘完成。分类文件冲突在「分类与标签管理」中备份后选择保留版本。

### 网页评论

在「当前页面」的「网页评论」输入框写下整页想法，点击「保存评论」或按 Ctrl+Enter（Mac 为 Cmd+Enter）保存，Enter 可换行。清空后保存可删除评论，网页标签和高亮仍保留。未保存输入在收起侧栏、切换侧栏标签页时保留，刷新或关闭网页前请保存。评论纳入侧栏搜索，显示在最近网页和标签结果中；只在插件侧栏展示，不生成原文高亮、位置条或悬停批注。

网页评论保存为 JSON 顶层 `comment`；开启自动生成后，也在 Markdown 的网页标签后、摘录前导出。没有高亮但有非空网页评论时同样支持导出；三项都为空（包括纯空白）时仅保存 JSON。旧 JSON 没有 `comment` 时按空评论处理。手动修改 JSON 的 `comment` 后刷新本地数据即可读回。多个网页标签页同时编辑时，旧输入不会覆盖最新评论；请先复制未保存输入，再使用「读取最新评论」核对。保存状态与文件冲突处理同下文。

```text
你选择的摘录目录/
├── 分类标签.json          # 分类/标签的稳定 ID 与名称
├── 网页标题.md
├── data/
│   └── YYYY-MM/
│       └── DD/
│           └── 文章标题--网页ID.json
└── 冲突备份/             # 仅在解决冲突时生成
```

- 开启「自动生成 Markdown 文档」后，有高亮、批注或非空网页描述的网页各生成一份 Markdown，直接放在根目录，文件名使用网页标题，正文不再重复页面标题。顶部 YAML 属性包含 `created`、`updated`、`category`、`tags`、`source`；时间保持原 ISO 8601 UTC 值，category 为唯一主分类字符串，tags 为小标签数组。每条内容使用引用块显示高亮原文、普通段落显示非空批注，并保留定位链接；空批注省略。Windows 非法文件名字符替换为下划线，过长标题截短；同名文档冲突时追加网页 ID。
- 开启 Markdown 自动生成后，刷新本地数据会迁移旧 Markdown 目录结构。只有新文档写入成功，且旧文件未被手工修改时才清理旧「标注.md」及空目录；手改内容保留并提示处理。
- 网页 JSON 与根目录「分类标签.json」共同构成主数据，备份或迁移资料库时请一同保留。旧版网页首次读取时自动迁移到稳定 ID 引用，原文章和标注 ID、评论与锚点保留。分类文件缺失、损坏或存在未知引用时会暂停相关同步并提示处理。
- 只有分类或标签不会生成 Markdown。开启自动生成时，清空最后一条高亮、批注及网页描述后，下次同步会移除未手工修改的导出文件；旧版生成的空内容文件也会清理。JSON 和网页记录保留，后续补充内容会重新生成 Markdown；手工修改的文件保留并提示冲突。
- JSON 是主数据；Markdown 是自动生成的阅读副本。手改 Markdown（包括 Obsidian 属性）不会同步回插件，也不会被静默覆盖。旧版未手改文件会自动升级；自定义正文或属性保留并提示处理。
- 新网页 ID 初次根据规范化 URL 的 SHA-256 前 16 位生成，此后作为固定身份保留；v2 不再要求 ID 随 URL 重算。查询参数保留，普通锚点和 Text Fragment 去除，`#/`、`#!` 路由保留。标题修改不会改变 ID 或导出文件路径。
- JSON 包含 `schemaVersion`、`id`、`url`、`originalUrl`、`title`、`favicon`、`markdownFile`、`categoryId`、`tagIds`、`category`、`tags`、`comment`、`createdAt`、`updatedAt` 和 `annotations`。`folderName` 仅用于旧目录迁移兼容；请保留这两个定位文件的字段。
- 每条标注包含 `id`、`text`、`note`、`tags`、`color`、`createdAt`、`updatedAt`、`anchor`。文字定位保留规范化引文 `exact`、前后文 `prefix/suffix`、文本位置 `start/end`、DOM 路径及引文出现次数；元素定位使用 `kind: "element"`，保存标签名、属性身份、内容摘要、资源链接和祖先上下文，`exact` 为创建时的可读快照，不伪造文字范围。含元素标注的网页使用 schemaVersion 3，旧插件不支持该格式。

**0.2.0 起，网页 JSON 为 schemaVersion 2：主分类修改 `categoryId`，标签修改 `tagIds`，值必须是根目录 `分类标签.json` 中存在的 ID。`category` 和 `tags` 仅为可读名称缓存，修改它们不会改变关联。重命名请修改分类文件中的 `name` 或使用仪表盘。网页评论修改 `comment`；摘录展示文字、批注与颜色修改 `annotations` 中的 `text`、`note`、`color`。** 颜色值为 `yellow`、`green`、`blue`、`pink`、`purple`。保留网页和标注 ID、URL、folderName、定位字段；要重新定位原文，请使用插件的「重新绑定」。时间使用 ISO 8601 UTC 格式。需要改变最近修改排序时，一并更新 `updatedAt`。

重开网页、打开侧栏、进入设置或点击设置中的「刷新本地数据」时检查 JSON 修改。无需手工改变 `updatedAt` 也能读回评论内容。第一版不持续监听磁盘上的外部改动；每分钟重试尚未完成的写入。

旧 Markdown 中的 `<!-- annotation:... -->` 对应 JSON 摘录 ID，是便于对照的内部标记，不是文本定位链接。HTML 注释在阅读预览中通常隐藏，在源码模式仍可见。1.0.7 不再导出这些注释，也不导出顶部的 `local-web-clipper` 注释；完整 ID 和定位信息仍保存在 JSON，回到原文链接保持不变。同步按完整已知导出内容识别文件，不只依赖注释标记。

## 保存状态与冲突

- **已保存到本地文件**：JSON 已同步；开启自动生成时，需要生成的 Markdown 也已同步完成。
- **已暂存浏览器 / 待同步**：内容已写入 IndexedDB，但尚未写入文件。请勿在同步完成前卸载插件或清除插件数据。
- **权限失效**：点击侧栏底部「设置」，在设置页点击「重新授权」并允许读写；成功后自动补写暂存标注。如果旧目录已移动或授权仍失败，点击「选择文件夹」重新选择原摘录目录。浏览器控制授权是否跨重启持久保留；插件不会绕过授权。
- **JSON 同时修改**：暂停覆盖，可查看两份内容后选择版本；被替换版本先存入「冲突备份」。
- **Markdown 手工修改**：原文件保留。可以继续不处理，或选择「备份手改内容并重新生成」。
- **JSON 错误或文件被删除**：不清空浏览器批注，不直接重建覆盖；在设置中修复文件或明确选择保留哪份数据。
- **部分写入失败**：保留待同步状态并重试，不重复追加摘录。

目录切换会把当前浏览器数据合并到新目录，旧目录不变；同一网页两份不同数据由用户选择。恢复已有数据时，安装插件后选择原目录即可递归读取 data 下的 JSON，也兼容旧「原始数据」目录。

多个标签页对同条标注提交旧版本时会拒绝覆盖并保留当前输入。文件写入前再次检查文件内容；但浏览器文件接口不能锁定外部编辑器，建议避免在点击同步的同时让其他程序持续改写同一个 JSON。

## 实现与权限

- `src/content.tsx`：封闭 Shadow DOM 内的 React 交互界面，选区、侧栏、轨迹与悬停窗口。
- `src/anchors.ts`：规范化文本索引、上下文消歧、动态页面恢复及 CSS Custom Highlight 绘制，不拆改原网页文本节点。
- `src/element-model.ts`、`src/element-anchors.ts`、`src/ElementUI.tsx`：元素数据校验、捕获与身份核验、父子层级选择和独立虚线覆盖层。
- `src/background.ts`、`src/sync.ts`：后台操作串行化、IndexedDB 持久化、外部文件检查、冲突与重试。
- `src/settings.tsx`、`src/files.ts`：用户目录授权和 File System Access API 读写。

HTTP/HTTPS 站点权限用于选区标注和重访自动恢复；`scripting` 用于对已打开网页补注入，`alarms` 用于重试同步，`unlimitedStorage` 用于本地摘录缓存。代码和界面全部随扩展打包，不远程加载执行代码，不上传批注。站点图标使用原网页提供的图标地址，浏览器可能请求该图标。

普通页面脚本不能通过 `host.shadowRoot` 直接读取批注界面。封闭 Shadow DOM 不等同于对恶意网页的完整安全隔离；网页仍控制自身布局和正文。

## 第一版边界

不支持 Chrome 内部页面、扩展商店、PDF、跨域 iframe、封闭 Shadow DOM 内正文或 Canvas 文字；只处理顶层普通网页。全文替换、未适配的翻译结构、正文删除后可能无法定位，届时保留批注并允许重新绑定。极长引文生成的 Text Fragment 链接可能受到聊天工具长度限制或目标浏览器兼容性影响。

### 沉浸式翻译中的高亮

从 0.2.22 起，文字摘录保留原文段落、列表、显式换行及中英译文边界，编辑窗、侧栏和保存内容均保留这些换行；0.2.43起悬停仅展示评论正文，并保留评论自身换行。已有的单行摘录在当前页面准确定位、且文字与保存内容一致时，会补回展示换行；不会自动覆盖原记录或手动编辑内容。仅因窗口宽度产生的自动折行不会写入摘录。

从 0.2.20 起，在沉浸式翻译的中英对照页面选择中文，会保留中文摘录并关联英文原文。译文未变时精确高亮；关闭译文或译文措辞变化时，以虚线标记对应的英文或中文段落，侧栏会说明是段落定位，悬停仅展示评论。重新显示原译文后自动恢复精确高亮，刷新网页后也会恢复；复制的定位链接使用原文。

支持本次样本中的段落、标题、列表与表格单元格结构（原文容器带 `data-imt-p="1"`，内部有唯一的 `.immersive-translate-target-wrapper`）。跨段选区分开绘制，不把夹在中间的译文误涂。无法可靠关联的结构会提示，并保留普通文字定位；不保证纯译文模式、其他翻译工具或未来变更的 DOM 结构。旧记录没有英文关联信息，需要在双语页面通过“重新绑定”重新选择一次。

不含全文剪藏、独立阅读器、随机回顾、AI、云同步或携带批注的分享链接。

从 0.2.11 起，旧「原始数据」及 data 平铺目录中的文章 JSON 会在正常同步时迁移到日期目录。先复制并校验内容，再移除未变化的旧文件和空目录；遇到不同内容的重复版本或读写错误会保留数据并提示处理。分类标签.json 保留在根目录，Markdown 阅读副本和冲突备份沿用原有位置。
